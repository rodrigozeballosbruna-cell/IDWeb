Estándares Web de la W3C

¿Qué es la W3C?

El World Wide Web Consortium(W3C) es un organismo que desarrolla estándares para asegurar el correcto funcionamiento de la Web a largo plazo.

Estándares

  • XML (Extensible Markup Language): Lenguaje donde podemos crear etiquetas para guardar información facilmente.
